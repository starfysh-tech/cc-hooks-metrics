The problem

AI agents operate in the dark

  • No visibility Claude Code runs shell commands, edits files, spawns subagents. You see the output. You don't see the timing, failures, or patterns behind it.
  • No guardrails Without active checks, an agent can rm -rf, commit broken types, or read your .env. You find out after the damage.
  • No trend data Hook latency creeps up. Steps start timing out. Failure rates spike. Without week-over-week telemetry, you're debugging symptoms, not causes.
How it works

Wrap every hook.
Store every run.
Report what matters.

A passthrough shell wrapper captures wall-clock timing, exit codes, git context, and stderr for every Claude Code hook event. Data goes to a local SQLite database. A Python report turns it into actionable insight.

01
Claude Code event
PreToolUse, PostToolUse, or Notification fires
02
hook-metrics.sh
Wraps the hook script with /usr/bin/time -p, captures context
03
Hook script
Guard, lint, test, or audit script runs. Exit code preserved.
04
hooks.db
Row inserted: timestamp, step, duration, exit code, branch, repo
05
Report
Rich terminal output, JSON export, or OTel spans on demand

Export

Ship spans to any
observability backend

Zero external dependencies. Full OTLP/HTTP JSON protocol. Privacy-first redaction built in. Pipe to Jaeger, Grafana, Honeycomb, or Claude itself.

  • Hook spans hook.{step} Kind: CLIENT. Duration, exit code, branch, commit, repo, stderr snippet on failure.
  • Tool spans tool.{name} Kind: INTERNAL. From audit_events. Redacted inputs by default.
  • Automatic redaction Hostnames hashed (SHA256[:12]). Paths reduced to basename. Commands to first word. Override with --include-sensitive.
